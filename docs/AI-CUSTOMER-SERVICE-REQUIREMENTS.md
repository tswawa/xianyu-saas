# AI 客服与安全规范

本文档说明 xianyu-saas 的 AI 客服架构、人格预设、上下文装配与安全门禁。

## 1. 客服系统架构

客服系统采用三层应答机制：

1. **关键词规则优先**：
   - 优先匹配商品专属规则，未命中时匹配店铺通用规则；
   - 命中规则直接返回预设话术，不产生模型调用。
2. **大模型回复**：
   - 规则未命中且满足回复条件时，调用配置的大模型接口生成回复；
   - 自动装配商品事实（标题、价格、规格）与知识库内容；
   - 经过站外导流过滤与防虚假承诺校验后发送；
   - 回复发送受已配置的拟人随机延迟、营业时间与网络连接状态约束。
3. **人工接管**：
   - 操作人员在客服工作台介入某个会话后，触发该会话的人工接管冷却（`manual_takeover_cooldown_seconds`）；
   - 冷却期间仅抑制当前会话的自动回复链，避免与人工冲突；
   - 人工接管不影响其他买家会话，亦不暂停店铺已核验订单的发货流程。

## 2. 统一大模型连接

大模型连接配置归属于系统用户，在系统设置中统一维护（`/api/settings/ai/connection`）。用户在前端输入并提交 API Key，浏览器端后续不回显明文且不进行长期本地缓存。服务端要求提供由 32 字节随机二进制经标准 Base64 编码（44 字符，示例：`base64.b64encode(os.urandom(32)).decode()`）的主密钥（`SAAS_AI_MASTER_KEY`），通过 HKDF 派生子密钥并以 AES-GCM 加密保存凭据。该连接供当前用户管理的所有店铺共用，支持以下功能：
- 店铺日常买家问答的 AI 客服兜底；
- 商品描述中的问答知识提取与整理；
- 店铺助手的多轮运维对话与工具参数组织。

系统目前作为单机自托管工作台运行，不设商业化付费会员体系或订阅计费功能。

## 3. 支持的大模型协议

系统适配以下主流调用格式：
- `openai_chat_completions`：标准 OpenAI 兼容接口（兼容 DeepSeek、通义千问、Kimi 等服务商）；
- `openai_responses`：OpenAI Responses API；
- `anthropic_messages`：Anthropic Claude 协议；
- `google_gemini`：Google Gemini API 协议；
- `ollama_chat`：本地部署的 Ollama 接口（本地访问默认关闭；环境变量 `SAAS_AI_ALLOW_OLLAMA_LOCAL=1` 仅针对 `ollama_chat` 开放本地回环与 HTTP 访问例外，普通私网地址仍被拒绝，`SAAS_AI_ALLOW_HTTP_LOCAL` 本身不放开地址限制）。

## 4. 人格预设体系

系统提供常见的人格预设，并支持自定义参数：

| 人格预设 | 标识 | 风格特点 | 适用场景 |
| --- | --- | --- | --- |
| 小喵客服 | `catgirl` | 亲切活泼，带有轻微口癖 | 文创、潮玩、动漫周边 |
| 亲切客服 | `friendly` | 常用礼貌用语与热情称呼 | 通用日用、服饰百货 |
| 专业客服 | `professional` | 用词规范，重点突出商品规格与参数 | 数码、工具、专业资料 |
| 自然表达 | `none` | 日常卖家沟通口吻，无特定人设 | 个人闲置、二手转让 |
| 自定义 | `custom` | 自由设定称呼、口吻、回复长度限制与表情使用倾向 | 特殊类目与个性化店铺 |

### 边界约束与转人工条件
- **禁止承诺（`forbidden_claims`）**：明确禁止 AI 在未获授权时承诺虚假库存、私下退款或站外交易；
- **转人工规则（`handoff_rules`）**：当买家提出退款申请、差评争议或大幅议价超出预设范围时，触发转人工待办。

### 知识整理功能
在商品设置中提供知识整理能力，操作人员粘贴说明文本后调用模型提取常见问答，经人工确认后保存生效。

## 5. 安全过滤门禁

大模型生成的文本在发送前须通过以下校验：

1. **反站外导流过滤**：通过正则表达式匹配微信、QQ、手机号、支付宝等外部联系方式，降低触犯平台违规规则的风险；
2. **防虚假发货拦截**：拦截模型文本中声称“已发货”、“款项已到账”等承诺。发货流程由独立状态机在核验待发货订单后执行；
3. **防重复回复**：对比当前会话近期回复历史，相似度超过阈值时丢弃重复文本；
4. **长消息保护**：仅在 `conservative`（保守）策略下，当买家单次发送文本在去除空白字符后超过 240 字时，自动跳过关键词规则匹配，防止误判长文。

## 6. 对话沙盘与内容预览

工作台提供基于当前大模型配置的内容预览沙盘：
- 可以在保存上线前，模拟买家提问测试大模型的生成效果与知识库引用；
- 当前沙盘主要用于 AI 生成内容与提示词效果预览，不执行 Worker 运行时的关键词规则匹配，不作为全流程规则命中演练工具。
