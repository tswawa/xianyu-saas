# 公开发布自检清单

在对外发布新版本或向开源社区发布前，请按照本清单进行逐项核对，确保代码整洁、安全合规。

## 1. 敏感信息与安全自查
- [ ] 工作区与 Git 提交历史中无任何真实的 API Key、密码、Token、闲鱼 Cookie 或私人凭据；
- [ ] 无任何真实买家信息、真实订单号、商业卡密或私人网盘链接；
- [ ] `.gitignore` 与 `.dockerignore` 正常生效，`data/`、本地日志及临时文件未被提交；
- [ ] 配置文件仅包含 `*.example` 模板，无主机硬编码路径。

## 2. 社区与合规规范
- [ ] 根目录 `LICENSE`（GPL-3.0）与第三方许可证说明（`worker/NOTICE.md`、字体 LICENSE）齐全规范；
- [ ] 文档与免责声明清晰完整，明确提示使用者遵守平台规则；
- [ ] `README.md` 中的特性介绍、快速开始命令、截图链接测试正常。

## 3. 自动化门禁测试
- [ ] 运行并通过仓库合规检查：`python3 tests/repository-contract.py`；
- [ ] 运行并通过单元测试套件：`npm test`；
- [ ] 检查无异常代码格式差异：`git diff --check`。

## 4. 容器与部署验证
- [ ] Docker 镜像可正常完成构建：`docker compose build`；
- [ ] 容器启动后健康检查接口正常返回：`GET /health` 状态为 200；
- [ ] 数据卷 `./data` 可正常持久化数据库与配置。
