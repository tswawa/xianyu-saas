# 发布前检查清单

本清单用于将仓库或构建产物交给外部使用者前的最后检查。每项都应由发布者根据当前版本填写，不把未完成项包装成已验证事实。

## 源码与历史

- [ ] 工作区和提交历史不含凭据、登录态、真实业务数据或个人主机路径。
- [ ] 不含本机协作指令、内部交接资料、临时导出物或未授权第三方素材。
- [ ] `.gitignore`、`.dockerignore` 和构建脚本不会把运行数据、密钥或本地产物带入发布包。
- [ ] README、变更记录、部署指南和配置模板与当前代码一致。
- [ ] 所有相对链接、图片、字体和外部链接均已检查。

## 许可证与合规

- [ ] 根许可证、Worker 上游来源说明和第三方许可证文件完整。
- [ ] 新增代码、图片、字体、图标和示例数据均具备再分发授权。
- [ ] README 和许可证说明清楚标注第三方平台、隐私和服务条款责任。
- [ ] 文档没有宣称真实平台、真实订单、第三方模型或生产环境已经验收，除非存在独立证据。

## 技术验证

- [ ] 在干净工作树运行 `python3 tests/repository-contract.py`。
- [ ] 在与本次改动匹配的环境运行 `npm test` 和 `git diff --check`。
- [ ] 构建并检查 Docker 镜像、容器入口、数据卷和非特权用户配置。
- [ ] 检查 Nginx/systemd 模板、来源校验、内部路径、限流、安全响应头和密钥外置方案。
- [ ] 检查账号隔离、权限、恢复、迁移、数据保留和回滚路径。

## 发布说明

- [ ] 版本号、变更记录、升级步骤、回滚限制和已知问题已更新。
- [ ] 生产环境变量、密钥、域名、TLS、数据库和备份策略由部署环境单独提供。
- [ ] 发布包只包含运行所需代码和获授权的资源。
- [ ] 公开安全报告入口可用，Issue、讨论和贡献流程已指向正确文档。
