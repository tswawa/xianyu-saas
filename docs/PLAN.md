# 产品边界与发展规划

本文档阐述 xianyu-saas 的产品定位、核心边界与中长期规划。

## 产品定位

xianyu-saas 专为闲鱼卖家与个人店主打造，旨在解决多账号运营中**客服响应慢、夜间漏单、虚拟商品手动发货繁琐**三大核心痛点。

系统围绕六大核心模块构建：
1. **运营概览**：集中监控多店铺连接状态、今日消息量、自动回复率及待办事项；
2. **店铺管理**：官方二维码扫码直连，多账号一键切换；
3. **智能客服中心**：内置小喵/亲切/专业人设，结合商品专属规则与大模型兜底；
4. **自动化发货中心**：卡密库存池、网盘资源与固定资料发货，严格防超卖；
5. **客服会话工作台**：多店铺统一客服工作台，支持人工随时无缝接管与多图发送；
6. **订单与日志**：完整的订单核验记录与发货审计跟踪。

## 明确的边界约束

为保证账号安全与轻量高效，本项目明确**不做**以下事项：
- ❌ **不做任何违规自动化**：不碰自动擦亮、高频批量采集、批量搬运等极易导致封号的黑灰产行为；
- ❌ **不做未经验单的盲目发货**：绝不凭买家聊天一句话发货，必须经由闲鱼官方订单接口验证；
- ❌ **不增加重型中间件依赖**：坚持单机极简部署，不强制依赖 Redis、Kafka 等组件。
